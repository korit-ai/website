# korit.ai website

Marketing site for korit.ai, built with [Astro](https://astro.build).

See [CLAUDE.md](CLAUDE.md) for how this repo fits into the wider Korit
project registry, and [kb/project/implementation-plan.md](kb/project/implementation-plan.md)
for the roadmap, decisions, and open items.

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview   # serve the production build locally
```

Deploys automatically to GitHub Pages on push to `main` — see
`.github/workflows/deploy.yml`.
